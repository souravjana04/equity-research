Methodology Documentation

Our risk-adjusted return model utilizes a modified Sharpe ratio, incorporating a dynamic risk-free rate derived from the 3-month Treasury bill yield curve, smoothed over a 90-day rolling window to mitigate short-term volatility spikes.
The sentiment tags (Positive, Cautious, Negative) are generated using a proprietary fine-tuned FinBERT model trained on over 50,000 earnings call transcripts. It emphasizes context-aware financial terminology rather than generic sentiment.
